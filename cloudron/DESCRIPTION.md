Loica is a self-hosted Markdown editor for writing together in real time.

Sign in, create a workspace, and edit documents with your team. Changes sync
live between browsers, with cursors and presence, so two people can work in the
same paragraph without stepping on each other. Everything is stored as
Markdown — no proprietary format to escape from later.

### Writing

* Real-time collaborative editing with live cursors and presence
* Inline comments, threaded on any selection
* Version history with a diff view
* Export to PDF and DOCX, rendered on the server with no external binaries
* File uploads embedded directly in documents

### Organising

* Personal and team workspaces with role-based permissions
* Folders with drag-and-drop
* Public share links, and per-document sharing with users or groups
* Search across your documents

### Extending

Anything beyond the basics ships as an optional extension an admin turns on
from the admin panel: presentations, grammar checking via LanguageTool,
AI-assisted proofreading and translation, and single sign-on. The same
architecture takes custom document types, auth providers and export pipelines.
